# Student Performance Prediction

## Project Description
A Flask-based web application that predicts student
performance based on marks.

## Technologies Used
- Python
- Flask
- Git
- GitHub
- Jenkins
- Docker
- Pytest
- Prometheus

## Features
- Student marks input
- Performance prediction
- Automated testing
- CI/CD integration
- Docker containerization
- Application monitoring

## Run Application

Install dependencies:

pip install -r requirements.txt

Run:

python app.py

## Run Tests

python -m pytest -v
